
# Kalkulator-cli

Mój projekt kalkulatora działającego w terminalu. Został stworzony w ramach nauki programowania i służy do wykonywania różnych działań matematycznych.

Projekt rozwijałem stopniowo, wraz z nauką programowania dodawałem nowe funkcje i ulepszałem istniejące rozwiązania.
## 🚀 Funkcjonalności

- Dodawanie i odejmowanie
- Mnożenie i dzielenie
- Potęgowanie i pierwiastkowanie
- Mediana, dominanta i średnia
- Silnia
- Historia wykonywanych działań

## 🛠️ Technologie

- Python
- Visual Studio Code Terminal

## 📦 Instalacja

Sklonuj repozytorium:

```bash
git clone https://github.com/USERNAME/PROJECT.git
```

Przejdź do folderu:

```bash
cd PROJECT
```

## ▶️ Uruchomienie

Po uruchomieniu programu w terminalu użytkownik może wybrać interesującą go operację i wprowadzić wymagane wartości.

Kalkulator wykonuje wybrane działanie i wyświetla wynik bezpośrednio w terminalu.
